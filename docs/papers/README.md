## Lean links

Every theorem in the papers links to its Lean declaration at a fixed commit, so the links do not move when the
code changes. `scripts/papers/leanlinks.py <commit>` reads the Lean files at that commit, writes the line of every
declaration to `leanlinks.tex`, and checks that every `\lean{File}{name}` used in the papers exists (exit code 1 if
one is missing). The papers use commit `e3d934be83`, whose CI run (build and axiom audit) passed.

## Build

```
python3 scripts/papers/leanlinks.py e3d934be831e9878655d2999fbd6e8fe20d7ffeb
python3 scripts/papers/figs_paper1.py     # Paper I figures
python3 scripts/papers/figs_paper2.py     # Paper II figures (each construction is checked numerically)
python3 scripts/papers/figs_paper3.py     # Paper III new figures (from docs/patterns/*_nd.json)
cd docs/papers/I-cube-centre  && latexmk -pdf cube-centre.tex
cd docs/papers/II-width-ball  && latexmk -pdf width-ball.tex
cd docs/papers/III-patterns   && latexmk -pdf patterns.tex
```

Paper III reads its catalogue numbers, tables and older figures from `docs/patterns-paper/` (generated by
`scripts/patterns/`), so every number has one source.
